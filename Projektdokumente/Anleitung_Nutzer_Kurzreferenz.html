Für Nutzer · Zugang + Bedienung auf einer Seite · Stand Juni 2026

1. Zugang (Handy)

  1. Tailscale → Verbunden (grün)
  2. Browser → Lesezeichen DigiWiki

Timeout? Flugmodus an/aus → Tailscale neu → URL erneut.

2. Bedienung

SchrittAktion
1Tab Wiki & Daten
2Modus Auto
3Frage tippen / 🎤 diktieren
4Enter / Fragen
5📌 Export / 👁️ Ausblenden unter Antwort

Export: Markieren → unten „Zusammenfassen & speichern“ → Ordner Antworten

Verlauf löschen: System-Status → Chat-Verlauf leeren

3. Antworten verstehen

SymbolQuelleErgebnis
🗄️DatenbankTabelle (Firmen, Personen, Zahlen)
🧠WikiText + Quellen (Dokumente)

Auto: Erst Datenbank, bei leerem Ergebnis Wiki.

4. Beispiel-Fragen

Datenbank:

  • Wer ist GF bei Hexal?
  • Adresse von Klosterfrau
  • Firmen in Köln

Wiki:

  • Was steht im Vertrag über …?
  • Brandvoice Hans zu …

5. Grenzen & Hilfe

  • PC des Admins muss laufen
  • Nur ein Gerät gleichzeitig
  • KI kann irren → Quellen prüfen
  • Hilfe: Admin + Screenshot

Mails / WhatsApp / Agenda: Tab wählen, KI-Entwurf, prüfen. Versand oft nur mit Outlook am PC.

Merksatz: Tailscale grün → DigiWiki öffnen → Auto-Modus → konkret fragen
